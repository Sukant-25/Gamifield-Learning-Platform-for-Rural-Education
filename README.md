# 🌱 AURA-Learn
### Gamified Learning Platform for Rural Education

AURA-Learn is an educational web platform designed to make learning more interactive, engaging, and accessible for rural students. It combines educational content, quizzes, games, rewards, and progress tracking to create a fun learning experience.

The project aims to reduce barriers to digital education through bilingual learning support, engaging activities, and offline-learning capabilities where supported by the implementation.

---

## 🎯 Project Objectives

- Make learning more engaging through gamification.
- Provide students with interactive educational resources.
- Support learning through quizzes, challenges, and educational games.
- Encourage consistent learning through points, badges, levels, and rewards.
- Help teachers monitor student learning progress.
- Improve accessibility through Tamil and English language support.
- Support learning in areas with limited internet connectivity.
